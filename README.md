# shiny-Python-project
Python Pygame project made in college ( Shoolini University) by Priyam Jha (GF202565177) &amp; Sumit Chandra (GF202565240). It is an NPC behavioral System. 

This project merges reactive logic, spatial coordination, and generative decision-making. The system transitions from a stealth prototype into multi-agent logic, culminating in an SLM cognitive layer. The core architecture relies on Python, a local SQL database (SQLite) for memory matrix logging, and behavior trees modifying AI utility scores based on player action history.
